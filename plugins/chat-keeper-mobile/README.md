# chat-keeper-mobile · 对话管理（手机适配版）

把 [Sky-lll27/DSH-chat-keeper](https://github.com/Sky-lll27/DSH-chat-keeper)（对话管家）的**客户端重写成手机友好的整页布局**。
原版把管理面板挂在「右侧栏 tab」里，手机端没有/放不下右侧栏，装上去就乱；本版把它放进
**设置 → 对话管理**（整页，卡片式列表），Host 能力完全一致：

- 跨工作区的对话总表（标题 / 工作区 / 最近活动 / 归档标记 / 运行状态）
- 正文搜索（走 DSH 全文索引，中文子串可搜）
- 批量归档 / 取消归档（勾选后底部操作条；运行中的会话会先确认「停止并归档」）
- 可恢复删除 + 回收站（删除/恢复/清空 = 复制指令 → 粘贴到输入框发送，由系统完成磁盘操作）
- 时间筛选（7 / 30 / 90 天前的）、显示已归档开关、一键刷新

## 用法

1. 安装本插件（**先卸载原版 DSH-chat-keeper**，否则两个插件的系统工具会重名冲突）。
2. 打开 **设置 → 对话管理**。
3. 点卡片打开会话；勾选后底部条一键归档/取消归档/复制删除指令。

## 安装

```bash
dsh plugin --profile web add /本地路径/plugins/chat-keeper-mobile
```

或在「插件管理 → 添加插件」里填本目录绝对路径。装完**重启一次 App** 让工具与索引生效。

## 说明

- Host 半（`index.js` + `lib/`）原样来自上游 DSH-chat-keeper v0.5.x（MIT），未改动。
- 适配 DSH 0.2.0-rc.2；安装后会同时打开 DSH 的全文索引（`session-query-sqlite` `openAt: first-search`）。
- 不联网；删除是磁盘操作，指令走聊天框由系统执行。
